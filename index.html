Security

Auto-accept is OFF by default. If enabled, any device that knows your 4-digit code can send files directly.
Security Notice: Uses public PeerJS signaling. Files are P2P encrypted, but IDs are discoverable. For private networks, host your own PeerServer.
Pairing Codes: 4-digit codes are public on the signaling server. Treat them as temporary identifiers, not passwords. Codes can be guessed or scanned.

About

Blip is a hardened iOS-style PWA for direct WebRTC file transfer. No external trackers. No IP lookups. All metadata stays on device.
